Knowledge, embedded.
Runs anywhere.
No internet required.

ELF is a format for bundling a knowledge base, a chat assistant, and optional local-model inference into a single portable HTML file — the document and the AI that knows it, together.

# write a KB JSON, generate the wiki

What you get

Three files. Infinite wikis.

[01]
ELF generator
Python script with zero dependencies beyond stdlib. Point it at a KB JSON — get back a fully offline HTML wiki with embedded chat assistant.
[02]
KB schema
An annotated JSON schema any LLM can fill in from a one-sentence topic prompt. Articles, equations, code blocks, tables — all supported.
[03]
Offline assistant
Every generated wiki ships with a keyword-retrieval chatbot. Paste a Claude API key for smarter answers — or leave it offline forever.
How it works

Three steps. No server.

01
Write a KB JSON
Use the schema as a guide — or prompt any LLM: "fill in _schema.json for Introduction to Thermodynamics."
02
Run elf_gen.py
One command. Reads your JSON, renders articles, inlines CSS/JS, writes a single .elf.html.
03
Share the file
Email it, host it as a static site, or put it on a USB drive. No server. No login. No expiry.
The format

Human-readable. AI-writable.

The KB schema is designed to be filled in by a language model from a short prompt. Every field has an inline comment explaining what goes there.

// _schema.json — the format contract { "manifest": { "title": "REQUIRED. e.g. 'Intro to Thermodynamics'", "file_id": "REQUIRED. slug → becomes the filename", "accent": "OPTIONAL. hex color. default #ff6b3d", "license": { "name": "CC BY-NC-SA 4.0" } }, "articles": [ /* array of wiki pages */ ], "chunks": [ /* Q&A pairs for the offline assistant */ ] }
Get started

Download. Run. Ship.

↓ elf_gen.py ↓ _schema.json ↓ quarter_car.json (example)
# generate the demo wiki
python elf_gen.py kb/quarter_car.json
# generate from your own subject
python elf_gen.py kb/thermodynamics.json --out site/thermo.elf.html
